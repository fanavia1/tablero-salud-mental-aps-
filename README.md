# Tablero de proyección de programas de salud mental 2026

Servicio de Salud Maule. Proyección de ejecución a diciembre 2026 de IAAPS 9, COMGES 8.1 y 8.2, Salud Mental y Bienestar Psicosocial, Establecimientos Dependientes y PASMI.

Datos REM enero a septiembre 2026. Planillas de programas al 23 de octubre.

Publicado con GitHub Pages desde la rama `main`: el archivo `index.html` es el tablero completo.
